# Agents

Small, practical AI-agent projects with synthetic data and reproducible local demos.

## Projects

- [Rebate Investigation Agent](Rebate%20Investigation%20Agent/README.md) — a Python and OpenAI Agents SDK prototype for investigating customer rebates. Its spreadsheet-backed demo and unit tests run without an API key. Using the AI agent is optional and requires your own OpenAI API key.

Start with the project README for setup, sample questions, architecture, evaluation instructions, and security boundaries.

All sample customer and transaction data is fictional. This repository is for learning and demonstration, not production financial decisions.
